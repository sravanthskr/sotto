Required if voice fails 3 times or to change security settings.

Google setup (owner)

One-time, by the app owner only: paste the OAuth client (Desktop app) from the Google Cloud console. This becomes the app's identity — every user just clicks Connect and signs in. End users never see this screen.

Connect email

Gmail: Account → Security → 2-Step Verification → App passwords, then paste the 16-character password. Outlook: use an app password if 2-step verification is on.

Link calendar

Google Calendar → Settings → your calendar → “Secret address in iCal format”. Read-only: the assistant can see events but can't change them.
